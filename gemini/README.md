# 🪐 GEMINI BRIDGE & AUDITORIA - J.A.R.V.I.S. // ANTIGRAVITY IDE

Esta pasta é o **Canal Direto de Comunicação e Auditoria Forense** entre o usuário, o assistente JARVIS e a IDE Antigravity.

---

## 📂 Arquivos Desta Pasta

1. **`input.txt`**:
   - **Canal de Mensagem Direta**: Digite qualquer instrução, comando ou pedido de desenvolvimento aqui e **salve o arquivo**.
   - O assistente JARVIS detecta automaticamente a alteração, despacha o prompt para o agente autônomo da IDE Antigravity (`agy`), atualiza a resposta e notifica o usuário!
   - Você não precisa abrir o navegador ou falar no microfone se preferir trabalhar diretamente por arquivos na IDE.

2. **`latest_response.md`**:
   - Contém a resposta técnica mais recente gerada pelo agente Antigravity ou pelo JARVIS.

3. **`audit.jsonl`**:
   - Registro estruturado em JSON Lines de **todos** os comandos, chamadas de ferramentas e respostas trocadas no ecossistema (ideal para auditoria programática ou análise por agentes).

4. **`commands.log`**:
   - Registro cronológico contínuo e legível para leitura e acompanhamento humano rápido.
